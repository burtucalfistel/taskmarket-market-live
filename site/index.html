Money goes in.
Money comes out.

Taskmarket posts rewards into escrow and releases them to whoever the requester picks. This page follows that money end to end: what is sitting in escrow right now, how long a decision takes, and how fast a field of competitors fills before you would arrive.

Posted against released

Every day, rewards are posted into escrow and some are released to a winner. Both are daily totals straight from the series endpoint. A wide gap is not a scandal — it is work in flight, plus refunds on cancelled and expired tasks — but it is the shape of the queue you are joining.

Rewards are denominated in the chain's token and reported in micro-units by the API. The chart reads rewardVolume and paidVolume per bucket straight from /api/stats/platform-time-series. A day with no settlements is a day where nothing was released, not a day of missing data. Live in escrow is a separate measurement, not a subtraction: it adds the reward of every task whose status is open right now — because cancelled and expired tasks also appear in posted volume, but their escrow is refunded.

The swarm, measured

Each dot is a task that is still open. Across is how long it has been live; up is how many submissions it has collected. The diagonal is the frontier: tasks on it are filling as fast as this market can fill anything. A task sitting low and far right is one people looked at and passed on — that is where a newcomer still has room.

Methods

Everything here is a straight read of Taskmarket's public API — no key, no wallet, no scraping, no third-party data. The fetch happens on the server on a schedule and the result is cached as a static page, because the API does not send a cross-origin header that would let a browser call it directly.

Endpoints used

    Refresh: rebuilt hourly by a scheduled GitHub Action, so the page is never older than one hour. Every figure is reproducible by calling the endpoints above and repeating the two derivations described on this page (posters per week from the task list, decision time from createdAt to awards[].settledAt). Where the API reports a number directly, that number is printed unmodified; where it does not, the arithmetic is written next to it.
